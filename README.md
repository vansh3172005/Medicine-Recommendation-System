# 💊 AI Medicine Recommendation System

An AI-powered system that predicts possible diseases based on user symptoms and recommends relevant medicines using machine learning.

---

## 🚀 Overview

This project leverages machine learning to analyze user-input symptoms and predict potential diseases. Based on the prediction, the system suggests possible medications.

The goal is to demonstrate how AI can assist in early-stage health awareness and decision support.

> ⚠️ **Disclaimer:** This system is for educational purposes only and should not be used as a substitute for professional medical advice.

---

## 🎯 Features

- 🔍 Disease prediction based on symptoms  
- 💊 Medicine recommendation system  
- 🧠 Machine Learning model (Random Forest)  
- 📊 Multi-class classification (40 diseases)  
- ⚡ Fast and efficient predictions  
- 🖥 User-friendly interface *(if applicable)*

## 📂 Dataset

The dataset includes:
- Symptoms as input features  
- Corresponding diseases as target labels  

The model was trained on data covering **40 different diseases**.

---

## ⚙️ How It Works

1. User inputs symptoms  
2. Data is preprocessed and formatted  
3. Trained ML model predicts the disease  
4. System recommends relevant medicines based on prediction
